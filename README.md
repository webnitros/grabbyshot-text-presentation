# Работа с текстом в GrabbyShot

Интерактивная презентация сценария из пяти экранов: черновик, выбор тона,
правка результата и вставка сообщения в чат.

Сайт работает как один автономный `index.html`, без сборки и внешних ресурсов.
В примере используются вымышленные сообщения; исходное видео в репозиторий не входит.
